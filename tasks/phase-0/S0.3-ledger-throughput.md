# Spike S0.3 — Ledger write path at 10k events/s, zero loss

**Phase:** 0 · **Kill-risk rank:** 3 · **Owner:** —
**Kills:** *Does the ledger keep up with a busy agent?* If SQLite (modernc.org/sqlite, pure Go) with WAL + group-commit can't sustain the target write rate with the hash chain computed inline and zero loss, the write path is redesigned before anything is built on top of it. This spike's numbers become gate **G1**.

## Goal
Sustain **≥ 10,000 events/s** end-to-end — CBOR encode → BLAKE3 leaf → Merkle-segment accumulate → group-committed SQLite insert — with **zero dropped events** and p99 commit latency **< 15ms**, on laptop-class hardware.

## Setup
- modernc.org/sqlite, WAL mode, `synchronous=NORMAL`, single writer goroutine.
- BLAKE3 + canonical CBOR encoders.
- A synthetic event generator producing a realistic mix (exec/fork/fs/connect) — no kernel needed; this isolates the storage layer.
- Run on both an M-series Mac and a mid-range Linux box.

## Steps
1. Generate a bounded, reproducible stream of N=10M mixed events.
2. Pipe through the real encode→leaf→segment→commit path with group-commit batching (≤ 10ms or 512 events).
3. Seal segments at 4096 events / 60s; write Ed25519 checkpoints every 64 segments (or 5 min pending), chained ledger-wide via `prev_checkpoint_hash` (v1.1, TRUST §5).
4. Measure sustained throughput, p50/p99 commit latency, DB growth, and confirm `verify` passes on the result.
5. Stress: burst to 50k/s briefly and confirm the token-bucket governor sheds by value and emits `gap` events (D14/P5) rather than losing silently.

## Success criteria
- [ ] ≥ 10k events/s sustained over the full 10M run, zero loss.
- [ ] p99 group-commit < 15ms.
- [ ] `rana verify` passes on the produced ledger (chain + Merkle + signatures).
- [ ] Under 50k/s burst: no silent loss; every shed interval has a `gap` event with correct counts.
- [ ] DB-on-disk growth is linear and reasonable (record bytes/event after path interning).

## Deliverable
`spikes/S0.3-report.md`: throughput/latency tables per machine, bytes/event, governor behavior under burst, and the concrete G1 threshold to enforce in CI.

2–3 days.
